# Data Dictionary

The table below documents the columns present in `Loan_Default_csv.xlsx`. Descriptions are kept at a practical project level; the source dataset may contain categorical codes whose exact meanings depend on the original dataset documentation.

| Column | Description |
|---|---|
| `ID` | Loan/application identifier. |
| `year` | Application year. |
| `loan_limit` | Loan-limit category. |
| `Gender` | Applicant gender field in the source data. |
| `approv_in_adv` | Whether approval was indicated in advance. |
| `loan_type` | Loan type/category. |
| `loan_purpose` | Purpose of the loan. |
| `Credit_Worthiness` | Credit-worthiness category. |
| `open_credit` | Open-credit indicator. |
| `business_or_commercial` | Business/commercial loan indicator. |
| `loan_amount` | Requested loan amount. |
| `rate_of_interest` | Loan interest rate. |
| `Interest_rate_spread` | Interest-rate spread. |
| `Upfront_charges` | Upfront loan charges. |
| `term` | Loan term. |
| `Neg_ammortization` | Negative-amortization indicator. |
| `interest_only` | Interest-only payment indicator. |
| `lump_sum_payment` | Lump-sum payment indicator. |
| `property_value` | Property value associated with the loan. |
| `construction_type` | Construction type. |
| `occupancy_type` | Property occupancy type. |
| `Secured_by` | Security/collateral type. |
| `total_units` | Number of units. |
| `income` | Applicant income. |
| `credit_type` | Credit-data type. |
| `Credit_Score` | Applicant credit score. |
| `co-applicant_credit_type` | Co-applicant credit-data type. |
| `age` | Applicant age group/value in source data. |
| `submission_of_application` | Application submission category. |
| `LTV` | Loan-to-value measure. |
| `Region` | Region category. |
| `Security_Type` | Security type. |
| `Status` | Loan default target used by the model. |
| `dtir1` | Debt-to-income ratio measure. |
